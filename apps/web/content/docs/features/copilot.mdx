Copilot appears next to every slide in the editor. Actions:

- **Rewrite** — punchier title + subtitle
- **Tighten** — shorter, more specific subtitle
- **Generate narration** — 20-second first-person script
- **Suggest new slide** — propose a slide that fills a gap

Rate limit: **50 copilot requests per user per day**.
