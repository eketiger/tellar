---
title: Key concepts
description: Vocabulary. Five terms you'll see everywhere in the product.
---

- **Tellar / teller** — a single deck. A tellar has slides, an optional narration
  recording, an optional knowledge base, and zero or more shares.
- **Share** — a revocable link that exposes a tellar to viewers under a set of
  access rules (email gate, passphrase, invite, public) and permissions (agent,
  recording, download, watermark).
- **Viewer** — someone who opens a share. Identified by email when the gate asks
  for one; never holds an account.
- **Agent** — Claude answering viewer questions using only the tellar's content,
  narration transcripts, and attached knowledge base.
- **Copilot** — Claude helping the creator *while editing*: rewrite, tighten,
  generate narration, suggest a new slide.
