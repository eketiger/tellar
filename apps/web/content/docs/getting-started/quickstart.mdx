---
title: Quickstart
description: Create a tellar, share it, and watch someone read it.
---

## 1. Sign up

Go to [/register](/register) and create an account. The signup flow creates
a personal workspace and a free plan. Google and GitHub OAuth are supported.

## 2. Create a tellar

From the dashboard, click **+ New tellar**, give it a title, and you land in the editor.

## 3. Edit slides

Every tellar starts with one slide. Click the title to edit inline, and use the
copilot buttons to rewrite, tighten, or generate narration with Claude.

## 4. Share it

Open the **Share** tab. Pick an access mode:

- **Email gate** — anyone from an allowed domain can open the link
- **Invite only** — only the listed emails
- **Passphrase** — one shared secret
- **Public** — anyone with the link

Toggle permissions for the agent chat, download, watermark, and screen recording
block, then copy the link.

## 5. Watch the funnel fill up

The dashboard tab shows unique viewers, per-slide dwell time, drop-off, and
which questions the agent answered.
