---
title: Account settings
description: Profile, workspace, members, usage, billing, security.
---

Open **Settings** from the avatar menu. Tabs:

- **Profile** — name, email, provider (read-only)
- **Workspace** — rename, slug, plan
- **Members** — invite / remove / change roles
- **Usage** — agent queries, recording minutes, storage, seats used vs. limit
- **Billing** — plan, invoices, upgrade/downgrade via Stripe Checkout
- **Security & privacy** — data export, account deletion
