### Email + password

<Tabs items={['cURL', 'TypeScript']}>
  <Tab value="cURL">
  ```bash
  curl -X POST http://localhost:3333/api/auth/login \
    -H "Content-Type: application/json" \
    -c cookies.txt \
    -d '{"email":"martin@tellar.studio","password":"demo1234"}'
  ```
  </Tab>
  <Tab value="TypeScript">
  ```ts
  const res = await fetch('/api/auth/login', {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    credentials: 'include',
    body: JSON.stringify({ email, password }),
  });
  ```
  </Tab>
</Tabs>

A successful response sets the `tellar_jwt` cookie (httpOnly, SameSite=Lax). Include it on
every subsequent request.

### OAuth

Hit `GET /api/auth/oauth/google?code=...&redirect_uri=...` from your callback handler.
The server verifies the token with Google / GitHub, upserts the user, and sets the cookie.
