title: Overview
description: Tellar's REST API.
---

The Tellar API is REST, JSON-encoded, and authenticated with an httpOnly JWT cookie named
`tellar_jwt`. All endpoints are versioned only by route path — there is no `/v1` prefix yet.

- Interactive reference — [/api-reference](/api-reference)
- Raw OpenAPI spec — [/openapi.yaml](/openapi.yaml)
